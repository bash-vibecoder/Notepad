AnoteP changes, November 27, 2026:
- Native Windows edition replaces the previous Electron desktop host.
- AnoteP application name, executable metadata, penguin icon and settings path.
- Automatic updates and the plugin-download administrator are disabled. No
  updater, network installer, browser runtime or third-party plugins are bundled.
- Existing Electron workspace is preserved and exported once to recovered copies
  under %APPDATA%\AnoteP\Native\Recovered. Original documents are not overwritten.

The native interface, sessions and preferences follow Notepad++, rather than
the Android/previous Electron interface. Recovered copies are UTF-8; consult
the preserved workspace.json for original file locations/encoding preferences.

Corresponding source: the AnoteP-1.2.0-windows-source.zip asset in the same release.
It contains the patched Notepad++ source, dependencies, build scripts and icon.
